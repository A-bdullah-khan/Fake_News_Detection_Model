# Fake News Detection Model

A modular, production-ready Machine Learning pipeline built with Python and Scikit-Learn to classify news articles as **Real** or **Fake**. Achieves **~98.6% accuracy** using TF-IDF feature extraction.

## Tech Stack & Dependencies
1) **Language:** Python 3.10+
2) **Libraries:** Scikit-Learn, Pandas, NumPy
3) **NLP Vectorizer:** TF-IDF (Term Frequency-Inverse Document Frequency)
4) **Algorithms:** Logistic Regression, Decision Tree, Gradient Boosting, Random Forest
